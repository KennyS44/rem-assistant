# Рэм — локальный голосовой помощник для Windows

Скажи «Рэм» — и управляй компьютером своими словами. Всё работает на твоём ПК:
распознавание речи, понимание команд и их выполнение. Без облака и подписок.

**Скачать:** https://kennys44.github.io/rem-assistant/

## Как устроено

```
микрофон → сторож (Vosk, только слово «рэм», ~5% одного ядра)
         → проверка + распознавание фразы (GigaAM v3, CPU, ~0,4 с)
         → быстрый путь (частые команды без модели, мгновенно)
           или языковая модель (Qwen3 4B в Ollama, родной вызов функций + проверка аргументов)
         → подтверждение голосом для опасного → выполнение → ответ голосом
           (голос Windows или нейроголос Silero — отдельная программа RemVoice)

колонки (WASAPI loopback) → если «рэм» прозвучало и там — это видео, а не человек
```

| Модуль | Что делает |
|---|---|
| `rem/listen.py` | микрофон, двухступенчатое слово активации, распознавание |
| `rem/fastpath.py` | частые команды без модели |
| `rem/brain.py` | запрос к Ollama (вызов функций), проверка умений и аргументов |
| `rem/skills/` | умения; новое — функция с декоратором `@skill` |
| `rem/assistant.py` | план → подтверждение → выполнение, игровой режим |
| `rem/echo.py` | что играет в колонках — чтобы «Рем» из аниме не будил помощника |
| `rem/speech.py`, `rem/voicepack.py` | голос Windows / нейроголос Silero, высота и темп |
| `rem/update.py` | проверка релизов на GitHub и тихая установка поверх |
| `rem/ui.py` | трей, настройки, первый запуск, проверка слова |
| `voice/rem_voice.py` | RemVoice — программа озвучки на torch, собирается отдельно (`voice.yml`) |

## Разработка

```
pip install -r requirements.txt pytest
python -m pytest tests                      # тесты, без микрофона и модели
python -m rem --selftest                    # самопроверка
python -m rem --text "открой ютуб" --dry    # как понята команда, без выполнения
python -m tests.eval_brain --model qwen3:4b-instruct-2507-q4_K_M   # точность модели, нужна Ollama
```

Новое умение:

```python
@skill("say_hello", "Поздороваться", "Поздороваться с пользователем.",
       examples=["привет"], category="Прочее")
def say_hello(ctx):
    return "Привет!"
```

Сборка установщика идёт автоматически в GitHub Actions на Windows (`.github/workflows/build.yml`):
тесты → самопроверка → PyInstaller → самопроверка собранного `Rem.exe` → Inno Setup.
Тег `v*` публикует релиз с `RemSetup.exe`; установленный Рэм находит его сам и предлагает обновиться.
Тег `voice-*` собирает и публикует `RemVoice.zip` (нейроголос), не делая его «последним» релизом.
